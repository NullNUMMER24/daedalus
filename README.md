# daedalus
Daedalus like the greek inventor and master craftsman
## Naming ideas
- Labirynth => Resource graph
- Ariadne => state thread
- Icarus => host agent

# What should it do
Daedalus should be an infrastructure management tool. So what I want is a centralized and simplified way to manage my homelab. I want to be able to manage VM's as well as K8s clusters using this tool.

As interfaces I thought about a more terminal friendly aproach like a cli and a non-tech-user-friendly like a Website
